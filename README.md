# 萌芽守卫 · Sprout Guard

一款原创、无需安装的花园塔防网页游戏。收集光能，布置四种植物守卫，抵挡三波逐渐增强的暮影怪物。

🎮 **[在线试玩](https://hhhoratioxu.github.io/Sprout-Guard/)**

## 游戏特色

- 5 行 × 8 列战场，支持手机触控和电脑鼠标
- 阳光花、豆荚炮、木灵卫、冰晶蕨四种原创守卫
- 伞帽怪、苔靴怪、藤石巨怪三类原创敌人
- 光能收集、卡片冷却、减速、一次性萤光屏障与三波难度
- 暂停、合成音效和浏览器本机最高分
- 纯 HTML、CSS、JavaScript，无框架和外部依赖

## 怎么玩

1. 点击“开始守卫”。
2. 收集战场上的发光能量球。
3. 选择守卫卡片，再点击空草地完成布置。
4. 每一行最左侧的萤光屏障能自动清场一次；屏障耗尽后不要让怪物再次越线。
5. 坚持到进度条结束，并清除剩余怪物即可获胜。

电脑上可按 `1`–`4` 选择守卫、按空格暂停、按 `Esc` 取消选择。

## 本地运行

这是一个静态网页项目，直接打开 `dist/index.html` 即可游玩，也可以用任意静态文件服务器托管 `dist/` 目录。

## 项目结构

```text
dist/
├── assets/          # 原创角色图集
├── game.js          # 游戏状态与战斗逻辑
├── index.html       # 页面结构
└── styles.css       # 响应式界面与动画
```

## 原创与许可

本项目借鉴经典路线塔防这一通用玩法，但名称、角色、美术和代码均为独立创作，与 PopCap、EA 或《植物大战僵尸》没有关联。角色图集使用 OpenAI 图像生成工具按原创设定制作。
